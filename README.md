🌟 Project Overview

An interactive Sales Analytics Dashboard designed to analyze business performance, track key metrics, and generate meaningful insights through dynamic visualizations.

✨ Key Features

💰 Revenue Analysis – Track total revenue and profitability.

📦 Order Analysis – Monitor total orders and sales performance.

🌍 Regional Analysis – Compare sales across different regions.

📈 Sales Trends – Analyze monthly and yearly sales growth.

🏆 Top Products – Identify best-selling products.

🎯 Category Analysis – Understand product category performance.

🎛️ Interactive Filters – Explore data dynamically.
